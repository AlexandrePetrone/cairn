# Security

## Reporting a vulnerability

Do not open a public issue for a security problem. Report it privately from
the **Security** tab of the repository, with **Report a vulnerability**:
only the maintainers read it.

Say what you found, how to reproduce it and what it lets someone do. Cairn
holds the issues of several clients on one instance, so anything that shows
a user what their role or their account should hide (another workspace,
private issues, comments or files) is a vulnerability, as is anything that
lets them act beyond their role.

## Supported versions

Cairn has no release yet: fixes land on the `main` branch only.
